Повна українська локалізація магазину та адміністративної частини
Версія 4.1.0.0 для Opencart 4.1.*
Сторінка з оновленнями перекладу: 
https://opencartforum.com/files/file/6584
=================================================================

Установка:

1. Перейдіть в меню Extensions -> Installer
2. Натисніть кнопку Upload та оберіть файл ukrainian_language.ocmod.zip
3. Натисніть кнопку Install на доповненні "OpenCart 4 Ukrainian Language"
4. Перейдіть в меню Extensions -> Extensions, оберіть тип доповнень Languages та натисніть кнопку Install доповнення "Українська локалізація"
5. Перейдіть у налаштування перекладу та переведіть у стан Включено параметри "Статус перекладу" та "Статус модуля", та збережіть зміни

На вкладці Додаткові налаштування ви можете скористатись можливістю додати переклад для деяких параметрів:
- Додати SEO URL для української мови, з префіксом /ua
- Додати валюту Гривня (у разі її відсутності)
- Додати переклад назви групи покупців за замовчуванням
- Додати переклад стандартних одиниць виміру
- Додати переклад стандартних одиниць ваги
- Додати переклад назв стандартних інформаційних сторінок
- Додати переклад стандартних опцій
- Додати переклад стандартних статусів замовлень
- Додати переклад стандартних статусів наявності на складі
- Додати переклад стандартних статусів повернення
- Додати переклад стандартних операцій повернення
- Додати переклад стандартних причин повернення

6. За потреби зробіть українську мову основною у налаштуваннях магазину: System -> Settings -> Налаштування магазину -> вкладка Local

Після установки пакету локалізації необхідно додати переклад для всіх обов'язкових полів в налаштуваннях модулів, шаблону, тощо.

Також необхідно додати ЧПУ для української мови всюди де це доступно (товари, категорії, статті, тощо)
